Saya membuat program Sistem Perhitungan Biaya Parkir menggunakan function. Function `hitung_biaya_parkir()` digunakan untuk menghitung total biaya berdasarkan jenis kendaraan dan lama parkir.

Pada function tersebut terdapat parameter `jenis_kendaraan` dan `durasi`. Saya menggunakan percabangan `if` dan `elif` untuk menentukan tarif. Jika kendaraan yang dimasukkan adalah mobil, tarifnya Rp5.000 per jam, sedangkan jika motor tarifnya Rp3.000 per jam.

Setelah tarif ditentukan, biaya parkir dihitung dengan mengalikan tarif dengan durasi parkir. Hasil perhitungan kemudian dikembalikan menggunakan `return`.

Pada bagian input, saya memasukkan jenis kendaraan, jam masuk, dan jam keluar. Lama parkir diperoleh dari pengurangan jam keluar dengan jam masuk. Setelah itu, function dipanggil untuk menghitung total biaya parkir.

Terakhir, program menampilkan jenis kendaraan, jam masuk, jam keluar, lama parkir, dan total biaya parkir.
